How we check KLEAR

KLEAR rebuilds every number it shows from public sources with one command. Each build checks its own work, and a build that fails a required check never replaces the data the site serves. This page reads the results of the latest build directly, so it always matches what the site is serving.

Do the districts add up?

KLEAR places every 2020 census block in one House and one Senate district. If that is right, each district’s population matches the count the Census Bureau publishes for it. The Reapportionment Commission drew the districts on a smaller base that counts permanent residents only, so its numbers differ on purpose.

    How close are estimated district numbers?

    Some sources publish numbers only for census tracts or ZIP codes. KLEAR moves them into districts by where people live. To measure how well that works, KLEAR does the same with six counts the Census Bureau also publishes for each district, and compares the two.

    Are the assistant’s answers right?

    The assistant is scored on two sets of questions. The practice set is public, and its recorded answers are scored again against each new build. The held-out set is kept private so it cannot be used to tune the assistant. Only its totals are published.
